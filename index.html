1. Resumen y Objetivos del Proyecto

Problemática

En pequeños procesos industriales y laboratorios, la falta de control automatizado de variables como temperatura y flujo de fluidos genera ineficiencia energética e inconsistencia en la producción.

Solución Propuesta

Diseño y fabricación digital de un módulo automatizado basado en ESP32 con la capacidad de monitoreo de sensores industriales, actuadores PWM con algoritmo PID y comunicación WebSockets/MQTT.

💡 Requisito Fab Academy: Todo el proyecto ha sido diseñado, fabricado y programado desde cero utilizando herramientas de código abierto como KiCAD, FreeCAD y VS Code + PlatformIO.

5. Firmware y Algoritmo de Control

El código está desarrollado en C++ utilizando la plataforma PlatformIO / Arduino Framework sobre un ESP32.

code/main.ino 
// Ejemplo de Control PID en ESP32 para Proyecto Fab Academy 2026
#include <Arduino.h>
#include <OneWire.h>
#include <DallasTemperature.h>

#define ONE_WIRE_BUS 4
#define PWM_PIN 16

OneWire oneWire(ONE_WIRE_BUS);
DallasTemperature sensors(&oneWire);

// Variables PID
float setpoint = 37.5;
float Kp = 2.0, Ki = 0.5, Kd = 1.0;
float errorAccumulated = 0, lastError = 0;

void setup() {
    Serial.begin(115200);
    sensors.begin();
    ledcAttachChannel(PWM_PIN, 5000, 8, 0);
    Serial.println("Sistema de Automatización Inicializado...");
}

void loop() {
    sensors.requestTemperatures();
    float currentTemp = sensors.getTempCByIndex(0);
    
    float error = setpoint - currentTemp;
    errorAccumulated += error;
    float dError = error - lastError;
    
    float output = (Kp * error) + (Ki * errorAccumulated) + (Kd * dError);
    output = constrain(output, 0, 255);
    
    ledcWrite(PWM_PIN, (uint32_t)output);
    lastError = error;
    
    delay(1000);
}
