## 🚀 Cómo Usar y Desplegar

1. **Editar contenido:** Puedes abrir `index.html` en VS Code u otro editor y reemplazar las imágenes de ejemplo o textos según el avance de tu proyecto.
2. **Prueba local:** Abre directamente el archivo `index.html` en cualquier navegador web.
3. **Despliegue en FabCloud (GitLab Pages):**
   - Sube este repositorio a tu carpeta en FabCloud.
   - Asegúrate de tener configurado tu `.gitlab-ci.yml` estándar para páginas HTML estáticas.
